# LOAF image workflow

Open `/dashboard/` and choose **Images**.

## Homepage stacks
Choose **Homepage product stacks**, select Notebooks or Sketchbooks, then choose **Add another photo**. Add as many as needed. The homepage rotates through them while keeping only a restrained number visible at once.

## Configurator
Choose **Configurator product gallery**, select the exact SKU, then choose an existing photo to replace it or **Add another photo**. The first photo is the main product image. Use the arrow controls in the image library to change the order.

## LOAF Out in the Wild
Upload and arrange real photographs in the dashboard. The storefront intentionally displays only the first four published photographs. Desktop shows four restrained rectangular tiles. Mobile turns the same four photographs into a horizontal swipe rail. Reorder the first four slots to control what appears publicly.

## Other locations
The same image manager supports the About page, student page, notebook reference, page close-ups, size guide and favicon.

## Performance
Upload PNG, JPEG or WebP source files up to 20 MB. The dashboard automatically creates several WebP sizes, preserves transparency and serves the correct size through the CDN.
