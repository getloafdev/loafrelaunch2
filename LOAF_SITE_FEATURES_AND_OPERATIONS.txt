FULL SITE DESCRIPTION, FEATURE SET AND OPERATING NOTES
Version: July 2026

============================================================
1. WHAT THIS SITE IS
============================================================

LOAF is a premium Bangladesh-made stationery storefront focused equally on heavyweight sketchbooks and 120 GSM notebooks. The site is designed as an editorial, highly visual shopping experience rather than a conventional product grid.

Core brand position:
- Human-made artwork only
- No AI-generated cover artwork
- Premium paper and practical A4/A5 formats
- Sketchbooks for drawing, observation and visual exploration
- Notebooks for planning, study, writing and business use
- Made in Bangladesh
- Established in 2020
- Cash on delivery

Primary technology:
- Static HTML, CSS and JavaScript storefront
- Netlify hosting and deployment
- Supabase database, authentication and storage
- Supabase Edge Function for server-validated checkout
- Responsive WebP media delivery through Supabase CDN

6. MEDIA PERFORMANCE SYSTEM
============================================================

Recommended source sizes:
- Product images: 1400 to 2200 px on the long edge
- Homepage artwork: 1600 to 2400 px
- Real-life photography: 1800 to 2800 px

Publishing process:
- The dashboard reads the source file
- It produces responsive WebP sizes
- It preserves transparent backgrounds when applicable
- It creates hashed filenames
- It uploads website delivery copies to Supabase Storage
- The storefront uses srcset and sizes so devices request an appropriate file
- Phones do not need to download the same large file as a 4K display

Security and quality rule:
- Keep master-quality photographs and artwork offline
- The website should contain optimized delivery copies only
- Any image displayed by a browser can ultimately be captured or screenshotted

9. SECURITY MODEL
============================================================

Backend protections:
- Supabase Row Level Security
- Admin-only product, inventory, order and media changes
- Admin-only Storage writes
- Server-side checkout validation
- Atomic stock changes
- CSRF is not applicable to bearer-token Supabase API calls in the same way as a cookie-authenticated PHP form, but access tokens must still be protected
- Admin session tokens are refreshed automatically

Public media model:
- Responsive optimized delivery copies use the public loaf-fast bucket for strong CDN caching
- Original master files should not be uploaded
- Hashed object paths reduce stale cache problems

Known security limitation:
- A visitor can capture an image once the browser displays it
- Right-click blocking or hidden URLs cannot provide absolute protection

============================================================
11. DEPLOYMENT AND MAINTENANCE
============================================================

Deployment:
- Deploy the complete ZIP through the existing Netlify project’s Deploys page
- Do not upload only index.html because the dashboard, routes, brand assets and configuration files are also required
- After deployment, hard refresh desktop browsers when testing changed code
- On iPhone, close and reopen the browser tab when Safari retains an old layout

Routine operating sequence:
1. Check Orders
2. Confirm stock and product availability
3. Upload or replace product images
4. Check homepage and real-life galleries
5. Open the storefront on desktop and mobile
6. Test one product configuration and the cart
7. Export orders periodically for backup

============================================================
LATEST OPERATING NOTES: PASSWORDS AND ANIMATIONS
============================================================

CHANGE THE ADMINISTRATOR PASSWORD
1. Sign in to the LOAF Control Room.
2. Open the Security tab.
3. Enter a unique password of at least 12 characters twice.
4. Select Change password.
5. Sign out and verify the new password before closing the current browser session.
6. Never place the password inside HTML, JavaScript, documentation, screenshots or shared files.

WHEN ANIMATIONS DO NOT APPEAR ON A WINDOWS PC
1. Hard refresh the site with Ctrl + Shift + R.
2. Check that the operating system is not configured to remove or reduce animations.
3. In Chrome, Edge or Brave, turn graphics acceleration on in browser system settings and relaunch the browser.
4. Temporarily disable extensions that modify motion, dark mode, CSS or page performance.
5. Turn off battery saver or aggressive power-saving mode while testing.
6. Test in an updated Chrome, Edge, Brave, Firefox or Safari browser.

IPHONE, IPAD AND ANDROID
1. Check Accessibility settings and turn off Reduce Motion or Remove animations when the full experience is desired.
2. Close the browser tab completely after a new deployment and reopen the site.
3. Keep the browser and operating system updated.
4. The site deliberately shows simpler static states when the device requests reduced motion.

LOAF OUT IN THE WILD
- The public homepage displays a maximum of four photographs.
- Desktop and tablet use a constrained two-by-two rectangle grid.
- Mobile uses one horizontal swipe rail with scroll snapping.
- Extra published photographs remain stored but are not displayed in this section until one of the first four is removed or reordered.
