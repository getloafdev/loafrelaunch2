# Latest LOAF fixes

## Configurator controls
- A4/A5 and Plain/Lined/Dotted use delegated click handling.
- The whole control surface is clickable.
- Decorative images and animation layers no longer intercept mouse or touch input.

## Mobile homepage
- The dark-to-white reveal has a much shorter scroll track on phones.
- Visitors reach the product stacks sooner without removing the glow effect.

## Flexible media
- Homepage notebook and sketchbook stacks accept unlimited photos.
- More than the visible stack count rotates in automatically without overcrowding the layout.
- Every exact SKU can have multiple configurator photos.
- Configurator thumbnails let customers switch between product views.
- LOAF Out in the Wild accepts unlimited photos and shows no captions or image numbers.
- The real-life gallery uses a responsive dense bento layout based on each image's actual dimensions.
- About and student landing pages have optional managed galleries.
- Admin users can add, replace, remove and reorder gallery photos.
